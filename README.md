# tapetime

Tape timestamps and time durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/tapetime/

## Install / run

```bash
git clone https://github.com/theworker02/tapetime.git
cd tapetime
node src/cli.js
node --test
```
